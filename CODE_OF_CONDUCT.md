# Code of Conduct

This project welcomes constructive contributions from people of every background and experience level.

- Treat other participants with respect.
- Give specific, considerate feedback about the work.
- Avoid harassment, discrimination, personal attacks, and disclosure of private information.
- Keep issues and pull requests focused on reproducible problems and useful improvements.

Maintainers may remove inappropriate content or restrict participation to protect the community. Report concerns privately to the maintainer through their GitHub profile so a suitable private channel can be arranged. Do not post sensitive reports in public issues.
